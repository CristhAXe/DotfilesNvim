## 📦 About

This is my personal Neovim configuration focused on a clean workflow for backend and JavaScript development.

I use this setup daily with Linux and terminal-based development environments.

## 🚀 Features

- Lazy-loaded plugins with LazyVim
- Simple and clean UI
- LSP support
- Treesitter
- Fast startup
- Terminal friendly workflow
- JavaScript development oriented

## 🛠️ Stack

- Neovim
- Lua
- LazyVim
- Linux

## 📚 Why I use LazyVim

- Easy to learn
- Fast and minimal
- Great defaults
- Easy plugin management
- Very customizable

## ⚠️ Notes

This config is still evolving and changing over time as I learn new things and improve my workflow.
